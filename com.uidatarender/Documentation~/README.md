# UI Data Render Documentation

This directory contains package-level design notes, validation artifacts, and governed unit-test records.

- `TextMeshProAdapter.md` describes the TextMeshPro integration.
- [ImageGenerationBatch.md](ImageGenerationBatch.md) explains explicit query reuse during repeated image generation.
- `Testing/` contains coverage history and EditMode test records.
- [HolderBucketScheduling.md](HolderBucketScheduling.md) describes opt-in snapshot queues, rotating buckets, atomic publication and ordered camera drawing.
- [DamageTextPlayback.md](DamageTextPlayback.md) describes fixed digit events, persistent geometry, GPU animation and deterministic playback.
- [DamageTextRendererComparison.md](DamageTextRendererComparison.md) covers shared-Quad/mesh comparison, staged sampling, report validity and experimental local-XY FP16; device acceptance remains pending.
